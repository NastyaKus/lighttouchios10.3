# Подтверждённый запуск 0.3.1 на Android

Обновление статуса: 2026-11-05. Это отчёт по сообщениям и скриншотам пользователя,
а не новый автоматический тест или запуск iOS в Linux-стенде.

## Что подтверждено на телефоне

- Подготовка и восстановление 18A5351d из локального IPSW, без Mac.
- Readback всех 45 dyld patch sites, настройка пяти служб в System launchd
  cache, успешный System unmount, cleanup/done, активация набора.
- Обычная загрузка iOS: Hello, выбор языка/региона, настройка, SpringBoard.
- Пользователь затем перезапустил систему и сообщил о работающем интерфейсе;
  на новых скриншотах видны обои, рабочий стол, экран установки обоев и меню
  выключения. Вид перезапуска (тёплый/холодный) отдельно не проверялся.

Устройство в диагностике: vivo V2338A, Android API 36, около 12 ГБ RAM;
пользователь сообщил Snapdragon 8 Gen 2.

Выбранные на последнем скриншоте настройки:

| Параметр | Значение |
|---|---|
| Ядра | 3 для iOS + 1 для SEP |
| RAM гостя | 4 ГБ |
| Экран | «Чётче», 828×1792 |
| Кэш трансляции | 512 МиБ |
| split-wx | выключен |
| Интернет через USB NAT | переключатель включён; отдельный сетевой тест не предоставлен |
| Вибрация/кнопки громкости/FPS | переключатели включены |

FPS на отдельных скриншотах менялся от 3 до 40. Это моментальные показания UI,
не воспроизводимый benchmark. GPU acceleration не реализовано. Пользователь
сообщил об отсутствии звука и первоначальных графических проблемах; позднее
показал интерфейс с обоями. Полное исправление графики и всех функций iOS
этим не доказано. Работа APFS/SEP unlock отдельно не трассировалась, но
пользовательский сеанс достигнут и после перезапуска.
